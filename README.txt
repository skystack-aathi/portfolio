AATHI RAJ — PORTFOLIO WEBSITE

Files
- index.html: page structure and portfolio content
- styles.css: responsive visual design
- script.js: language switching (DE / EN / FR / PT), mobile navigation

Preview locally
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. For best results, use a local static server or deploy to GitHub Pages.

Deploy to GitHub Pages
1. Create a repository (or use the repository you want to publish from).
2. Upload index.html, styles.css and script.js to the repository root.
3. In GitHub: Settings -> Pages -> Deploy from a branch -> main / root.
4. Save and wait for the published URL.

Before publishing
- Verify the experience dates and project descriptions.
- Add your preferred headshot if you want one; the current hero uses an original CSS data-architecture illustration rather than a stock photo.
- Add your CV PDF and link it if you want a downloadable résumé.
- Review the public phone number and email address.
- Project metrics and descriptions are based on the existing portfolio; confirm they are approved for public use.
- A home street address has intentionally not been included.
